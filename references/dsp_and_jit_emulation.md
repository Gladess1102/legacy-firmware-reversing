# 专有 DSP 架构反汇编与 PC 端 JIT 仿真方法论 (DSP & JIT Emulation)

当嵌入式固件使用非 x86/ARM 的冷门专有架构（如 Motorola DSP56000/DSP56004/DSP56300 24-bit DSP、TI C5000/C6000、ADSP 等）时，标准反编译工具（如 IDA Pro、Ghidra）往往缺乏足够支持，且缺乏真机源码调试器。本指南总结了从架构识别、桩替身隔离、外设协议级模拟到内存 Diff 定位核心状态变量的实战方法。

---

## 1. 异构架构识别与工具链搭建

### 1.1 Motorola DSP56k 家族核心特征
- **字长与内存模型**：
  - 指令字长严格为 24-bit。
  - 拥有分离的独立内存空间：`P`（程序空间）、`X`（X 数据空间）、`Y`（Y 数据空间）。
  - 双累加器 `A` 和 `B`（56-bit：A2/B2 扩展 8 位，A1/B1 高 24 位，A0/B0 低 24 位）。
- **指令特征**：
  - 并行移动语法：一条算术指令并行执行 1~2 个寄存器/内存搬运（如 `mac +x1,y0,b asl b #>$000064,y0`）。
  - 硬件循环机制：`rep #n`（单指令硬件重放）与 `do a0, label`（硬件循环堆栈，内嵌计数器）。

### 1.2 工具链选型
- 本机编译专有工具（如基于 Rust 的开源项目 `dsp56300` 引擎）：
  - 反汇编器：`dsp56300-disasm`
  - 汇编器：`dsp56300-asm`
  - 仿真器：基于 core 库构建轻量级执行器（如 `fmtrace`）。

## 2. 替身桩技术（The Surrogate Stubbing Pattern）

在老旧多任务 RTOS 固件中，驱动模块（Overlay / CID）通常动态加载于特定地址（例如 `P:0xB2C1`），其执行重度依赖常驻内核（ROM 或 Resident Section）提供的系统调用（如 `$6A4C`, `$68FD`, `$6659`）。

### 2.1 常见误区：陷入“重构整个操作系统”的泥潭
试图寻找并反汇编全部常驻内核、推导复杂的加载基址与重定位表，往往耗费数周却因跳板错位而持续跳飞到空内存。

### 2.2 破局法：手写微汇编桩替代常驻内核
无需实现整个操作系统，只需为目标模块调用的少数几个外部符号手写“替身桩（Assembly Stubs）”：
1. **数学除法桩 (`$6A4C`)**：
   ```asm
   ; 替代系统 48-bit / 24-bit 除法例程
   org p:$6a4c
   rep #24
   div y0, a
   rts
   ```
2. **消息记录桩 (`$68FD`)**：
   ```asm
   ; 替代系统消息泵，将参数 dump 到预留的观测内存区
   org p:$68fd
   move a1, x:$e000
   move b1, x:$e001
   rts
   ```
3. **状态提供桩 (`$67B3`)**：
   直接返回当前注入的受测变量（如档位、电量、音量）。

将手写桩编译为 LOD / 二进制，与被测模块一同载入仿真器，即可彻底摆脱外部依赖，让驱动模块在 PC 端 100% 独立稳定执行。

## 3. 外设协议级模拟（Peripheral Mocking）

驱动程序通常包含轮询外设状态的阻塞循环（例如通过 GPIO 模拟 3-Wire / I2C / SPI 与收音芯片、电源管理芯片通信）。

### 3.1 闭环状态机设计
如果直接运行驱动，代码因等待外设应答（如芯片 ID、就绪位）而陷入死循环。必须在仿真环境中挂载虚拟外设：
1. **总线捕获与解码**：
   - 在 GPIO 写寄存器（如 `x:$F401` DATA, `x:$F411` CLK, `x:$F403` CE）设置钩子（Hook）。
   - 捕获 CLK 上升沿采集 DATA，解码出读写方向、寄存器地址与写入值。
2. **可编程寄存器文件（Register File）**：
   - 预设只读寄存器的合法值（例如收音芯片 CHIP_ID = `0x09`）。
   - 对可写寄存器记录写入值并在后续读操作时回显。
   - 欺骗驱动认为硬件响应完美，从而驱动调谐、音量控制、搜台全流程自动走完。

## 4. 全内存 Diff 法定位关键分叉 (Full-RAM Diffing)

当静态代码庞大复杂、难以从反汇编中看出分支逻辑时，PC 端仿真器提供了降维打击的手段：**全内存差异对比法**。

### 4.1 操作规程
1. **确定临界输入点**：
   - 选取两个仅有一步之差、但真机行为发生质变的输入（例如调谐频率 $89.9\text{ MHz}$ 洪亮清晰 vs $90.0\text{ MHz}$ 声音骤降）。
2. **同周期运行与 Dump**：
   - 分别以两组输入初始化仿真器，执行完全相同的指令周期数（如 800,000 周期）。
   - 将执行结束时的全量数据空间（`X` 内存与 `Y` 内存）完整输出到文本文件。
3. **文本 Diff 提取分叉实体**：
   - 比较两份内存镜像。在数万个内存单元中，通常会惊人地收敛到仅有 1~2 个字节的差异！
   - 例如：`Y:$4DFC`（调谐档位影子字）：
     - $89.9\text{ MHz} \to 0x45$（档位 69）
     - $90.0\text{ MHz} \to 0x46$（档位 70）
4. **追溯消费者**：
   - 一旦锁定关键变量地址（如 `Y:$4DFC`），即可在反汇编中快速反查引用该地址的指令（`move y:$4dfc, a`），精确抓出指针运算公式（如 `r4 = 0x49FE - q`）以及数组 70 项越界的物理真相。
